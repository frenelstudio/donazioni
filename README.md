# Donazioni · Frenél Studio

Pagina per le donazioni a Frenél Studio: https://frenelstudio.github.io/donazioni/

- `index.html`: pagina principale (importo + Satispay / PayPal / carta tramite PayPal)
- `grazie.html`: ringraziamento dopo il pagamento
- `assets/config.js`: link, importi proposti e messaggio delle serate (si modifica solo questo per gli aggiornamenti ordinari)
- `qr/`: QR code che punta alla pagina (SVG vettoriale e PNG 4000 px)
